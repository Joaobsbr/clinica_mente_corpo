# Clínica Vida & Cuidado — HTML, CSS e JavaScript

Projeto front-end de um sistema de clínica, criado sem frameworks.

## Estrutura

- index.html — páginas públicas, login e sistema interno
- style.css — layout e responsividade
- script.js — navegação, dados de demonstração, cadastros e modais

## Como executar

1. Coloque os três arquivos na mesma pasta.
2. Abra `index.html` no Edge/Chrome.
3. Para entrar no sistema use:
   - E-mail: `admin@clinica.com`
   - Senha: `123456`

## Módulos incluídos

Site público, especialidades, profissionais, contato, login, cadastro de paciente,
dashboard, agenda, consultas, prontuários, profissionais, especialidades,
financeiro, relatórios e configurações.

## Importante

Este é um protótipo front-end. Os dados ficam somente no navegador enquanto a página
está aberta/recarregada. Para uso real com pacientes, seria necessário um backend,
banco de dados, autenticação segura, controle de permissões, HTTPS, auditoria e
cuidados específicos com dados de saúde e privacidade.
